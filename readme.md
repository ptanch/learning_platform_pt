# LMS API — Django REST Framework учебный проект

Этот проект создан в рамках изучения Django REST Framework (DRF).
Цель — разработать backend-часть LMS-системы, в которой пользователи могут размещать свои обучающие материалы: курсы и уроки.

Проект представляет собой REST API, возвращающий клиенту JSON-структуры, и используется как серверная часть для SPA-приложения.

## 📌 Функциональность проекта

На текущем этапе реализованы:

🔹 1. Подключение DRF

Создан новый Django-проект.
DRF подключён в settings.py через INSTALLED_APPS.

🔹 2. Модели

Созданы три основные сущности:
1. `User`
Модель размещена в приложении `users`.
Используется для хранения информации о пользователях системы.
2. `Course`
Размещена в приложении `lms`.
Отражает учебный курс.
Может содержать множество уроков.
3. `Lesson`
Также размещена в `lms`.
Связан с курсом отношением «один-ко-многим».

### Структура проекта:
```
project/
│
├── users/
│   ├── models.py  # User
│
└── lms/
    ├── models.py  # Course, Lesson
```

## 🔧 Реализованные эндпоинты
🔹 3. CRUD для Course (через ViewSet)

Использован `ModelViewSet` для реализации всех CRUD-операций:

- GET /courses/ — список курсов
- POST /courses/ — создание курса
- GET /courses/<id>/ — получение одного курса
- PUT /courses/<id>/ — полное обновление
- PATCH /courses/<id>/ — частичное обновление
- DELETE /courses/<id>/ — удаление

🔹 4. CRUD для Lesson (через Generic Views)

Использованы generics:

- `ListCreateAPIView`
- `RetrieveUpdateAPIView`
- `DestroyAPIView`

Реализованные эндпоинты:

- GET /lessons/ — список уроков
- POST /lessons/ — создание урока
- GET /lessons/<id>/ — просмотр урока
- PUT/PATCH /lessons/<id>/ — обновление
- DELETE /lessons/<id>/ — удаление

Generics позволяют точечно подбирать только нужный функционал и дают полный контроль над логикой.

## 🧪 Тестирование

Все эндпоинты проверены вручную через `Postman`:

1. Получение списка курсов и уроков
2. Создание сущностей
3. Обновление
4. Удаление

## 🚀 Как запустить проект

Клонировать репозиторий:
```
git clone <your-repo-url>
cd project
```

Установить зависимости:
Если используется `Poetry`:
```
poetry install
poetry shell
```

Выполнить миграции:
```
python manage.py migrate
```

Запустить сервер:
```
python manage.py runserver
```

Теперь API доступно по адресу:
http://127.0.0.1:8000/
